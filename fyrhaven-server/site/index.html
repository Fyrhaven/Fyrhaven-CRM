Self-hosted licence

      

        One licence, one machine. Follow the three steps that match what you are doing —
        each one tells you what to paste where.
      


      
    
        
  1. 
          
    1 Activate a new server
    
          
    
            On the server, open Dedicated server → Licence and copy the
            installation key (FHI-…). Paste it here and you get a
            licence bound to that machine.
          
    
          
    
            
            
          
    
          
    
            
    
            
            
    Paste it into the server: Dedicated server → Licence → Install licence.
    
          
    
        
    2. 

        
  2. 
          
    2 Release the old server
    
          
    
            On the server you are leaving, choose Release this installation. It shows a
            challenge. Paste it here to get a signed release code — the second
            half of the same handshake.
          
    
          
    
            
            
          
    
          
    
            
    
            
            
    Paste it back into the old server. It forgets the licence, and
              step 1 becomes possible on the new one.
    
          
    
        
    3. 

        
  3. 
          
    3 Check what is where
    
          
    Each licence shows the machine it is bound to. A licence that says
            not activated yet is free to use; one on a machine you no longer run is
            released with step 2.
